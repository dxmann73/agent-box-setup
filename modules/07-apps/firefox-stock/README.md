# firefox-stock

What: Stock Firefox browser for the daily host.

Does: Keeps the distribution Firefox available for utility browsing, local callbacks, and captive
portals. It does not change the default-browser policy.

Catalog metadata: see [Modular machine catalog](../../README.md) for typ, sit, scp, requires, and
ticks.

Recipe: [recipe.md](recipe.md)

Apply: `sudo ./apply.sh`

Verify: `./verify.sh`
