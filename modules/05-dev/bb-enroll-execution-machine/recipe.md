# bb-enroll-execution-machine recipe

Run in the guest-credentials window after `bb-server` is running and `agent-vm` exists. Enrollment
uses a one-time private command generated by the host BB server, so it cannot be scripted or logged
in this repository.

On the host server, create a manual execution-machine enrollment using BB's UI or CLI. Run the
generated command exactly once as the normal user in the agent VM. Do not commit, save, or paste the
command into a shell history that is shared outside that VM. Then rename the machine in BB and test
that a thread runs on the VM without exposing host execution.

```bash
cd ~/projects/agent-box-setup/modules/05-dev/bb-enroll-execution-machine
./verify.sh --target agent-vm
```

The verifier proves that enrollment state and an enabled BB user service exist locally. Confirm the
machine name and provider visibility from the host BB server separately.
